Act 2

The Binary Race

You are about to run the same computation seven different ways on the same hardware. Before running anything — commit your prediction.

Before you run — write your prediction in the sheet

Which binary do you think will be fastest?

How much faster than the slowest? Write a multiplier — for example 5x or 10x.

Commit to it before running anything.

Run All seven binaries in sequence — approximately 35 to 40 seconds
$ /opt/lab/mod01/run_binary_race.sh
Watch the output as it runs. Read each Wall time as it appears. Do not do anything else.
Which number to record The Wall time line in every run looks like this:

Wall time : 23.0877 seconds

Enter just the number — for example 23.09. Use the Wall time from the program output — not the real time line from the time command.

Act 3 · Phase C

NUMA

You are about to run the STREAM memory bandwidth benchmark three ways. The only thing changing between runs is where the memory lives.

Run Three NUMA configurations — approximately 15 seconds total
$ /opt/lab/mod01/run_numa.sh
How to read STREAM output STREAM produces a lot of verbose output. Ignore everything except the results table near the bottom of each run. Find the Triad row — it is always the last row in the table. Take the first number after Triad. That is your answer. Ignore all other columns and all other rows.
Function Best Rate MB/s Avg time Min time Max time Copy: 149267.6 0.008674 0.008575 0.008818 Scale: 123900.0 0.010366 0.010331 0.010417 Add: 135987.8 0.014144 0.014119 0.014169 Triad: 135930.5 0.014146 0.014125 0.014193

From the example above the number to record is 135930

Fill in the sheet — Section 4
  • First Triad number → No Binding column
  • Second Triad number → Local Binding column
  • Third Triad number → Cross-NUMA column

If Something Goes Wrong

Command not found
Check you are typing the full path. All scripts are in /opt/lab/mod01/
Wall time looks very different from everyone else
You may have OMP_NUM_THREADS set from a previous run. Reset it and rerun:
$ unset OMP_NUM_THREADS
SSH session froze
Close the terminal. SSH back in. Your work is not lost.
$ ssh userXX@mylab.hpc.now

Replace XX with your number.

Cannot find the right number in STREAM output
Find the results table near the bottom of the output. Find the Triad row — always the last row. Take the first number after Triad. Everything else is noise.
Not sure which column to fill in the sheet
The Wall time line in every program output starts with Wall time : — that is the number. The TRIAD bandwidth starts with Triad: — first number after it.
