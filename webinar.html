what you will do

You'll be given logins to a live cluster. Then we run the progression.

01

Run a job on a single core

Your first interaction with a real HPC cluster. Submit a job, watch it run, read the output. You'll see immediately how HPC job execution differs from running a process directly on a server.

02

Scale to multiple cores on one node

The same workload, parallelised across cores. Watch the scheduler allocate resources and observe how performance changes — and what stays the same.

03

Span across multiple nodes

Cross the boundary from single-node to distributed compute. This is the moment most engineers have never seen — a workload running simultaneously across separate machines, coordinated by the scheduler.

the inflection point
04

Run on standard Ethernet vs InfiniBand

Run the same distributed workload across both fabrics. The performance difference is not subtle. You'll see exactly why HPC clusters use high-speed interconnects — and what happens when MPI falls back silently to standard networking.

where things get interesting
05

Submit everything as a proper SLURM job

Take everything you've just run and submit it correctly through the scheduler — with resource requests, wall time, and output handling. This is how real HPC workloads run in production.
